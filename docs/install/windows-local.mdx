---
title: "Windows"
description: "Install OpenSRE on Windows with the PowerShell installer."
---

Open PowerShell. The installer does not need an elevated session.

## 1. Install and start OpenSRE

```powershell
& ([scriptblock]::Create((irm https://install.opensre.com/install.ps1))) -dc
```

```powershell
opensre
```

Create an OpenSRE account or sign in to activate the hosted model. The first prompt offers a demo; pick the CI/CD analysis of a repository on this machine, or choose **E** to skip it.

The installer puts `opensre.exe` in `%USERPROFILE%\.local\bin`. If `opensre` is not found, follow the PATH instructions printed by the installer or open a new terminal.

## 2. Connect tools

```bash
opensre integrations setup <service>
opensre integrations verify
```

## 3. Ask the agent

Ask in the interactive shell: *why is checkout latency spiking?*
