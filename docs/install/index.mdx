## Before you begin

Make sure you have:

- A terminal open in a code project
- A Git repository (recommended for the full workflow demonstration)

## Step 1: Install and start opensre

<Tabs>
  <Tab title="macOS and Linux">
    ```bash
    curl -fsSL https://install.opensre.com | bash -s -- -dc
    ```

    Prebuilt Linux binaries need glibc 2.35 or newer (Ubuntu 22.04 or comparable); see [Linux](/install/linux-local).
  </Tab>
  <Tab title="Windows">
    Open PowerShell and run:

    ```powershell
    & ([scriptblock]::Create((irm https://install.opensre.com/install.ps1))) -dc
    ```

    See [Windows](/install/windows-local).
  </Tab>
</Tabs>

Then start OpenSRE:

```bash
opensre
```

![OpenSRE CLI welcome screen with the sign-in prompt](/images/opensre-welcome.png)

For PATH troubleshooting and platform requirements, see [Install locally](/install/install-local).

## Step 2: Sign in

Choose **Sign in or create account** in the welcome screen. Your browser opens the OpenSRE sign-up page; sign in with email or another enabled provider. Signing in activates the hosted model, so you need no LLM key. Back in the terminal, OpenSRE confirms the session with the web app and opens the shell.

## Step 3: Pick what to do

The first shell prompt asks what you want to do:

```text
What would you like to do?
  (A) Analyze & improve a repo (recommended)
  (B) Keep my CI/CD healthy automatically
  (C) Open the shell
```

Choosing **B** asks how that should run:

```text
Keep my CI/CD healthy automatically
  (A) Run continuously on this machine (recommended)
  (B) Run one repair in OpenSRE Cloud
  (C) Connect Slack
```

Choose **A** to see what OpenSRE does with a repository on your machine: it
reads the last 30 days of GitHub Actions history and reports how reliable your
CI is and how much developer time it costs. It needs GitHub access: connect it
first with `opensre integrations setup github` (authorize in the browser, or
paste a token). Without it the flow stops and names that command. See
[CI/CD analytics demo](/cicd/cicd-analytics-demo).

Choose **C** to go straight to the prompt. Type `/demo` to open the menu again at
any time, or start with `opensre --skip-onboarding` to skip it.

## Step 4: Ask your first question

Describe what's going on in plain English:

```text
why is checkout latency spiking?
```

Connect the tools OpenSRE should read when you need them, from the shell (`/integrations setup github`) or the terminal:

```bash
opensre integrations setup <service>
```

## Stuck?

- **Command not found** — open a new terminal, or add the bin directory the installer printed to your PATH
- **The sign-in screen comes back after you signed in** — run `opensre account status`; it names what is wrong with the session
- **Anything else** — see [Quickstart troubleshooting](/getting-started/quickstart#troubleshooting)

Need deploy options beyond a laptop binary? See [Deployment](/guides/deployment).
