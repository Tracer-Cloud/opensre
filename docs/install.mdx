## Before you begin

Make sure you have:

- A terminal open in a code project
- A Git repository (recommended for the full workflow demonstration)

## Step 1: Install and start opensre

```bash
curl -fsSL https://install.opensre.com | bash
```

Then start OpenSRE:

```bash
opensre
```

![OpenSRE CLI welcome screen with the sign-in prompt](/images/opensre-welcome.png)

Use a macOS or Linux terminal. On Windows, use [WSL](/environments/windows-local).

For PATH troubleshooting and platform requirements, see [Install locally](/install-local).

## Step 2: Sign in

Choose **Sign in or create account** in the welcome screen. Your browser opens the OpenSRE sign-up page. Create an account or sign in using email or another enabled provider; a successful login activates the hosted model, so no separate LLM key is required. Add GitHub later as an optional integration if you want OpenSRE to work with repositories.

When that finishes, OpenSRE opens the interactive shell. Add tools later, when you need them:

```bash
opensre integrations setup <service>
```

For the guided integration and optional local-model wizard, run:

```bash
opensre onboard
```

To inspect or end the account session later:

```bash
opensre account status
opensre account credits
opensre account logout
```

`opensre credits` and `/credits` in the shell show the same hosted balance.

Then check that the tools you connected work:

```bash
opensre integrations verify
```

## Step 3: Ask your first question

Open the shell and describe what's going on:

```bash
opensre
```

Ask: *why is checkout latency spiking?*

Full walkthrough with screenshots: [Quickstart](/quickstart).

## Stuck?

- **Command not found** — open a new terminal, or add the bin directory the installer printed to your PATH
- **The shell keeps asking you to sign in** — run `opensre account status`; expired, revoked, incomplete, or unreachable sessions do not open the shell
- **Docker / `make` missing** — see [Quickstart troubleshooting](/quickstart#troubleshooting)

Need deploy options beyond a laptop binary? See [Deployment](/deployment).
