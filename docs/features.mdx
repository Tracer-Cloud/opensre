## Full list

**CI/CD:**

- 30-day CI reliability report for one repository, with developer hours lost and a comparison to two open-source projects — [CI/CD analytics demo](/cicd-analytics-demo)
- Fix failing GitHub Actions checks on a pull request or branch and push the repair — [Fix GitHub CI](/github-ci-fix)
- A recurring reliability agent, a bounded repair loop for one PR, and the managed service for organizations — [Keep CI green with an agent](/cicd/ci-repair-agent)
- One read-only scan for every failing PR and branch across your organizations — [Scan CI health](/github-ci-health-scan)

**Integrations:**

- 60+ tools across observability, incidents, cloud, code, messaging, databases, and workflows — [Integrations overview](/integrations-overview)
- Setup and verify with `opensre integrations setup` and `opensre integrations verify`
- Multi-instance providers for prod/staging pairs — [Multi-instance integrations](/multi-instance-integrations)
- Bring-your-own LLM: Anthropic, OpenAI, Gemini, Ollama, Bedrock, OpenRouter, and more — [LLM providers](/llm-providers)
- MCP connections from the shell (`/mcp`)

**Interactive shell:**

- Plain-language prompts that map to tools and slash commands — [Assistant](/interactive-shell-assistant)
- Full slash-command surface via `/help` — [Shell commands](/interactive-shell-commands)
- Goals that persist across turns until the finish line is met — [Goals](/goals)
- Sessions you can list, resume, compact, and branch — [Sessions](/sessions)
- Long-term memory across chats — [Memory](/memory)
- Local coding-agent fleet scan — [Fleet](/fleet)
- Reasoning effort control (`/effort` or `OPENSRE_REASONING_EFFORT`)

**Privacy and safety:**

- Reversible identifier masking before external LLM calls — [Masking](/masking)
- Command-history privacy controls — [Interactive shell privacy](/interactive-shell-privacy)
- Guardrails for hard-blocked secrets and PII

**Messaging and automation:**

- Chat delivery and triggers: Slack, Discord, Telegram, and more — [Messaging](/messaging)
- Scheduled digests, recurring prompt loops, and delivery jobs — [Cron](/cron)

**APIs and deployment:**

- HTTP API for health checks and alert intake — [HTTP API](/api)
- Python API for in-process agents — [Python API](/python-api)
- Local CLI, an organization-managed gateway, gateway daemon (`opensre gateway start`), or host on Railway / ECS / Vercel — [Deployment](/deployment)
- Local and enterprise install paths — [Install](/install)
