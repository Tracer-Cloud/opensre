OpenSRE answers production questions by querying the same tools your team
already uses. Connect an integration so OpenSRE can pull logs and metrics,
check recent deploys, and deliver findings to your channels.

There are 60+ supported integrations. Connect your stack so OpenSRE can pull
logs, check recent deploys, and deliver findings where your team already works.

## Two setup paths

| Path | Best for | How to configure |
| --- | --- | --- |
| Local CLI | Self-hosted `opensre` on your laptop or server | `opensre integrations setup`, plus env vars |
| Hosted (OpenSRE Cloud) | Org-wide connectors shared across users | Connect at [app.opensre.com](https://app.opensre.com) → Integrations |

Either path works on its own. When you are signed in and a service is connected
in both places, the OpenSRE app connection wins.

## Local CLI

```bash
opensre integrations setup
```

You can also set environment variables; OpenSRE picks them up on the next run.
See each integration’s page for the required variables, or
[Environment variables](/install/environment-variables).

### Verify

```bash
opensre integrations verify
opensre integrations verify datadog
```

In the interactive shell: `/integrations list`, `/integrations verify <name>`,
`/verify`, and `/health`.

To register more than one instance of the same provider (for example prod and
staging Grafana), see [Multi-instance integrations](/platform/multi-instance-integrations).

## Hosted (OpenSRE Cloud)

Connect services once at [app.opensre.com](https://app.opensre.com) →
Integrations and every signed-in surface uses them: the gateway, the
interactive shell, and the `opensre` CLI on any machine where you are signed
in. No local setup is needed on each laptop.

If the same service is also configured locally, the OpenSRE app connection
takes precedence. To use a local credential instead, disconnect the service in
the web app. `opensre integrations list` shows where each connection comes
from (`remote` or `local`).

Signed-out or offline machines fall back to local integrations only.
