---
title: "Windows"
description: "Install OpenSRE on Windows using the curl installer inside WSL."
---

Use [WSL](https://learn.microsoft.com/en-us/windows/wsl/install) to run OpenSRE in a Linux terminal on Windows. Open your WSL distribution and change to your code project before continuing.

## 1. Install and start OpenSRE

```bash
curl -fsSL https://install.opensre.com | bash
```

```bash
opensre
```

Create an OpenSRE account or sign in to activate the hosted model and open the interactive shell.

The [Linux guide](/environments/linux-local#binary-compatibility) lists supported distributions. If `opensre` is not found, follow the PATH instructions printed by the installer or open a new terminal.

## 2. Connect tools

```bash
opensre integrations setup <service>
opensre integrations verify
```

## 3. Ask the agent

Ask in the interactive shell: *why is checkout latency spiking?*
