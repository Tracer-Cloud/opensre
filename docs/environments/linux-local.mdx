Install OpenSRE on Linux (laptop, desktop, or a local VM), sign in to your account, then ask the agent your first question.

## 1. Install

```bash
curl -fsSL https://install.opensre.com | bash
```

You usually don't need `sudo`. If `opensre` isn't found after install, open a new terminal or add the bin directory the installer printed (often `~/.local/bin`) to your PATH.

### Binary compatibility

Prebuilt Linux binaries require **glibc 2.35+** (Ubuntu 22.04+ or a comparable distribution) and do not run on Alpine Linux. Use a supported Linux distribution or the [Docker guide](/environments/docker).

## 2. Set things up

```bash
opensre
```

Create an OpenSRE account or sign in to activate the hosted model. Add tools later, when you need them:

```bash
opensre integrations setup <service>
```

Then verify connected tools:

```bash
opensre integrations verify
```

## 3. Ask the agent

Chat with it in the shell:

```bash
opensre
```

Ask: *why is checkout latency spiking?*
