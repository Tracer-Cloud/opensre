Install OpenSRE on macOS, sign in to your account, then ask the agent your first question.

## 1. Install

```bash
curl -fsSL https://install.opensre.com | bash
```

You usually don't need `sudo`. If the terminal says `opensre: command not found`, open a new window or add the path the installer printed (often `~/.local/bin`).

## 2. Set things up

```bash
opensre
```

Create an OpenSRE account or sign in to activate the hosted model. Add tools later, when you need them:

```bash
opensre integrations setup <service>
```

Then check connected tools:

```bash
opensre integrations verify
```

## 3. Ask the agent

Open the shell and describe what's going on in plain English:

```bash
opensre
```

Ask: *why is checkout latency spiking?*
