## Full list

**CI/CD:**

- 30-day CI reliability report for one repository, with developer hours lost and a comparison to two open-source projects — [CI/CD analytics demo](/cicd/cicd-analytics-demo)
- Fix failing GitHub Actions checks on a pull request or branch and push the repair — [Fix GitHub CI](/cicd/github-ci-fix)
- A recurring reliability agent, a bounded repair loop for one PR, and the managed service for organizations — [Keep CI green with an agent](/cicd/ci-repair-agent)
- One read-only scan for every failing PR and branch across your organizations — [Scan CI health](/cicd/github-ci-health-scan)

**Integrations:**

- 60+ tools across observability, incidents, cloud, code, messaging, databases, and workflows — [Integrations overview](/integrations)
- Setup and verify with `opensre integrations setup` and `opensre integrations verify`
- Multi-instance providers for prod/staging pairs — [Multi-instance integrations](/platform/multi-instance-integrations)
- Bring-your-own LLM: Anthropic, OpenAI, Gemini, Ollama, Bedrock, OpenRouter, and more — [LLM providers](/platform/llm-providers)
- MCP connections from the shell (`/mcp`)

**Interactive shell:**

- Plain-language prompts that map to tools and slash commands — [Assistant](/getting-started/interactive-shell-assistant)
- Full slash-command surface via `/help` — [Shell commands](/getting-started/interactive-shell-commands)
- Goals that persist across turns until the finish line is met — [Goals](/getting-started/goals)
- Sessions you can list, resume, compact, and branch — [Sessions](/platform/sessions)
- Long-term memory across chats — [Memory](/platform/memory)
- Local coding-agent fleet scan — [Fleet](/platform/fleet)
- Reasoning effort control (`/effort` or `OPENSRE_REASONING_EFFORT`)

**Privacy and safety:**

- Reversible identifier masking before external LLM calls — [Masking](/platform/masking)
- Command-history privacy controls — [Interactive shell privacy](/platform/interactive-shell-privacy)
- Guardrails for hard-blocked secrets and PII

**Messaging and automation:**

- Chat delivery and triggers: Slack, Discord, Telegram, and more — [Messaging](/integrations/messaging)
- Scheduled digests, recurring prompt loops, and delivery jobs — [Cron](/platform/cron)

**APIs and deployment:**

- HTTP API for health checks and alert intake — [HTTP API](/guides/api)
- Python API for in-process agents — [Python API](/guides/python-api)
- Local CLI, an organization-managed gateway, gateway daemon (`opensre gateway start`), or host on Railway / ECS / Vercel — [Deployment](/guides/deployment)
- Local and enterprise install paths — [Install](/install)
